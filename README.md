# 안강진구청 메인화면

새빛민주공화국의 가상 지방자치단체 안강진구 홈페이지입니다. 제공받은 성남시청 저장본의 배너 크기(데스크톱 844 × 440px), 32px 모서리, 좌우 화살표, 우측 하단 컨트롤, 검색·바로가기 배치를 반영했습니다. 상징색은 #2A5CAA이며, 국기와 상단 로고는 사용자가 제공한 SVG 원본을 그대로 사용합니다. 메뉴와 홍보 내용은 안강진구에 맞추어 작성했습니다.

## 실행

`index.html`을 브라우저에서 열면 됩니다. 빌드나 설치 없이 동작하는 HTML/CSS/JavaScript입니다. GitHub Pages에도 그대로 사용할 수 있습니다.

## 구현 범위

- 요청한 GNB 전체 계층과 전체 메뉴, 모바일 메뉴
- 이미지 배너: 원본과 같은 Swiper 라이브러리, 5초 자동 전환, 500ms 가로 슬라이드, 순환 재생, 터치 스와이프, 이전·다음·정지·재생
- Pretendard GOV Regular/Bold 웹폰트 자체 호스팅(라이선스 포함)
- 새소식·고시 공고·입찰 공고·입법 예고·보도자료 탭
- 현재 메뉴 및 예시 게시물 대상 검색
- 화면 확대와 키보드 접근성, 반응형 레이아웃

게시물은 예시이며 상세 페이지, 게시판 백엔드, 로그인, 민원 접수는 연결되지 않았습니다. 링크를 선택하면 이 사실을 안내합니다. 실제 개인정보 수집이나 외부 서비스 호출은 없습니다.

## 배너 이미지 교체

1. `assets/banners/`에 이미지를 넣습니다. 권장 크기: 844 × 440px. JPG, PNG, WebP, SVG를 사용할 수 있습니다.
2. `banners.js`의 `src`를 해당 경로로 바꾸고, 이미지 내용을 설명하는 `alt`를 작성합니다.
3. 연결 메뉴는 `page`로, 실제 URL은 `href`로 지정합니다. 배열 항목을 추가하면 페이지 수가 자동 갱신됩니다.

현재 배너는 안강진구용 예시 이미지입니다. 화면의 모션 감소 설정이 켜져 있으면 자동 재생과 전환 애니메이션이 기본 비활성화되며, 재생 버튼으로 자동 재생을 켤 수 있습니다.

## 외부 자산

- Pretendard GOV: 원본에서 사용한 파일을 포함합니다. `assets/fonts/LICENSE.txt` 참조.
- Swiper: 제공받은 성남시청 저장본과 동일한 배포 파일. 소스 헤더의 MIT 라이선스 고지를 보존했습니다.
- 바로가기 아이콘: 디자인 참조용 성남시청 원본 자산의 강조색을 안강진구 상징색으로 수정했습니다.

## 상단 바와 구청장 섹션

- 상단은 원본의 `header-top`, `header-middle`(`top-menu`, `bottom-menu`, `logo`, `etc-menu`), `header-bottom`(`mobile-top`, `gnb`, `gnb-wrap type-depth3`) 구조를 사용합니다. 날씨와 AI 검색은 제외했습니다.
- 원본 CSS 규칙과 반응형 규칙은 `reference-layout.css`, 기관명·메뉴 개수 및 독립 페이지에 필요한 조정은 `header-mayor.css`에 있습니다.
- 구청장 섹션 순서: 메인 배너/생활서비스 → `mayor-section section` → 소식. 기존 `intro inner`는 제거했습니다.
- `site-content.js`의 `name`, `greeting`, `portrait`, `slogan`, `sloganAlt`, `banners`를 수정하면 구청장 이름, 인사말, 인물 이미지, 슬로건, 우측 소식 이미지를 바꿀 수 있습니다. 현재 인물은 가상의 한도윤이며 SVG 인물 이미지는 임시 삽화입니다.
- 원본 구청장 섹션의 배경 사진은 디자인 참조용 임시 자산입니다. 배경 파일은 `assets/reference/mayor_bg.png`, `mayor_bg1.png`, `mayor_bg_t.png`, `mayor_bg_m.png`에서 교체할 수 있습니다.
- 로그인·기관 사이트·다국어는 화면 안내만 제공하며 실제 인증·번역 서비스를 호출하지 않습니다.
